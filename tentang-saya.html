Halo. Nama saya andhika.
Website ini dibuat sebagai contoh untuk murid-murid saya dalam membangun website statis di Github yang gratis.

  • Pada Modul 1 diajarkan tentang membangun website hanya dengan HTML dan Table. Tanpa CSS. Anda sedang menempuh modul ini.
  • Di Modul 2, para murid diajarkan tentang bagaimana "mendandani" websitenya memakai CSS agar tampilannya lebih menarik.
  • Di Modul 3, barulah para murid diajarkan bagaimana cara membangun website yang responsif, menggunakan CSS dan JavaScript.

PENTING

Jangan memakai AI misalkan ChatGPT, Gemini, atau Claude AI. Hampir pasti dapat dideteksi oleh guru. Lagi pula modul 1 ini tidak mengajarkan tentang CSS dan JavaScript, melainkan mengajarkan tentang bagaimana membuat tampilan halaman web yang konsisten, tentang tautan (hyperlink) dan berbagai tag HTML dasar yang wajib dipahami oleh semua peserta didik.
